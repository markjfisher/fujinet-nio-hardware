# A500 expansion assets

The shared library supplies an 86-contact A500 logical symbol and a **male PCB
edge-finger footprint**. This directory was an empty template placeholder; it
is not a validated female mating-socket board.

A sidecar that plugs directly into the A500 needs a female socket. Reuse the
reviewed logical pin map, then select the actual connector and validate its
land pattern, mating orientation and case clearance. Do not assign the existing
male-edge footprint to that socket. See
[the R1 candidate](../../../amiga/integrated-a500-r1/README.md).
